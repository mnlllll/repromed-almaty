# Медицинский центр «Репро-Мед» (г. Алматы)

Веб-приложение клиники репродукции человека, диагностики (УЗИ Samsung H-60, биопсия за 1 день, кариотипирование за 5 дней), гинекологии, андрологии и процедурного кабинета по адресу: **г. Алматы, проспект Райымбека, 150 (уг. ул. Чайковского), 1-й этаж**.

## Основные возможности
- **Интерактивный 3D-атлас (Three.js)**: переключение стадий (`Бластоциста`, `Дробление`, `Генетика · ДНК`), вращение и разборка слоев.
- **Онлайн-запись на прием** и быстрый переход в **WhatsApp** (`+7 (701) 760-85-20`) и **звонок по Казахстану** (`+7 (727) 233-50-70`, `+7 (705) 148-62-08`).
- **Личный кабинет пациента**: демо-вход, регистрация/авторизация, управление визитами, просмотр результатов обследований и экспорт данных в JSON.
- **Push-напоминания о визитах**: Service Worker (`/sw.js`) + уведомления о приеме. *На Cloudflare HTTPS включается автоматически, поэтому Push работает сразу.*
- **Отзывы и карта 2ГИС Алматы**: живой виджет 2ГИС (фирма № `9429940000850084`), форма отзывов (`/api/reviews`) и поддержка синхронизации по ключу `DGIS_REVIEWS_KEY`.
- **Правовой пакет (РК)**: Политика конфиденциальности, Согласие на обработку ПДн и ИИН (Закон РК № 94-V), врачебная тайна (ст. 273 Кодекса РК № 360-VI), Пользовательское соглашение, Cookies/Push и медицинский дисклеймер.

## Деплой на Cloudflare (готово к запуску)

Проект адаптирован сразу под оба способа хостинга в Cloudflare — без Node.js/Express-зависимостей на edge:
- `worker/index.ts` + `wrangler.jsonc` — для **Cloudflare Workers (Static Assets)**
- `functions/api/[[path]].ts` — для **Cloudflare Pages (Functions)**
- `cloudflare/api.ts` — общий серверный API на Web Crypto / Fetch с поддержкой **Cloudflare KV** (`REPROMED_STORE`) и автоматическим fallback в память.

### Вариант 1: Cloudflare Workers (через GitHub или Wrangler — рекомендуется)
1. Загрузите проект в GitHub и в панели Cloudflare откройте **Workers & Pages → Create → Import a repository** (или локально установите `wrangler`).
2. Настройки сборки в Cloudflare:
   - **Build command:** `npm run build:cf`
   - **Deploy command:** `npx wrangler deploy` (подхватит `wrangler.jsonc` автоматически)
3. *(Опционально для постоянного сохранения записей и отзывов)* Создайте бесплатный **KV Namespace** в разделе **Storage & Databases → KV**, затем привяжите его под именем **`REPROMED_STORE`** (или укажите `id` в `wrangler.jsonc`).

### Вариант 2: Cloudflare Pages
1. В Cloudflare откройте **Workers & Pages → Create → Pages → Connect to Git**.
2. Настройки сборки:
   - **Framework preset:** Vite
   - **Build command:** `npm run build:cf`
   - **Build output directory:** `dist`
3. Папка `functions/api/[[path]].ts` подключится автоматически и будет обрабатывать все `/api/*` запросы.
4. Для постоянного хранения данных привяжите KV Namespace в **Settings → Functions → KV namespace bindings** с именем переменной **`REPROMED_STORE`**.

## Локальный запуск (Node.js 20+)
```bash
npm install
cp .env.example .env
npm run dev
```
После запуска приложение доступно на `http://localhost:3000`.

## Переменные окружения / Секреты
- `DGIS_REVIEWS_KEY` *(опционально)* — партнерский ключ 2ГИС Reviews API для автоматической подгрузки свежих отзывов из 2ГИС.
- `REPROMED_STORE` *(только Cloudflare KV binding, опционально)* — постоянное хранилище заявок, профилей и отзывов (без привязки работает в памяти изолята).
